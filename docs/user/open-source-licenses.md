# Open source licenses

AI Thing includes third-party software and adapted assets. To read their license and attribution
notices:

- On web and desktop, open **Settings → General**, find **Open source licenses** under **About**,
  and select **View licenses**.
- On mobile, open **Settings → About AI Thing → Open source licenses**.

The page lists the version when available, license identifier, and the parts of AI Thing that include
or use the item. This also covers optional device tools that AI Thing installs on demand instead of
bundling. Select a row to read the complete notice text. Use the search field to find a package,
version, license, or app component.
